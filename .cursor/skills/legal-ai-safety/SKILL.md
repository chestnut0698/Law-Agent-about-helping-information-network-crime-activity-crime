# 法律 AI 安全边界

## 绝对非目标

任何页面、服务、Prompt、报告和问答都不得：

- 认定是否构成帮信罪；
- 判断证据是否确实、充分；
- 自动评价证据能力、真实性或证明力；
- 输出确定刑期或最终量刑建议；
- 自动生成起诉书或办案决定；
- 进行地区犯罪预测或人群风险画像；
- 将未完成脱敏确认的真实材料发往外部模型；
- 展示或使用模型隐性推理作为业务依据。

## 允许表述

优先使用：

- “材料中已发现……”
- “当前材料中未发现……”
- “存在信息不一致，待人工核验”
- “可能适用的规范”
- “供人工复核的参考”
- “规范化计算参考，非最终量刑建议”

## 禁止或高风险表述

- “构成犯罪”
- “证据确实充分”
- “应判处……”
- “已证明”
- “不成立”
- “证据不足”，如果被用作实体结论
- “同案同判”，如果被用作确定结论

检测到高风险表述时不得只替换词语继续输出；应判断整个主张是否越界。

## 输入门控

安全门控只接收用户请求和案件元数据，不读取完整案卷正文。

输出：

- `ALLOW`
- `CLARIFY`
- `DENY`

拒绝时提供合规替代：

- 整理客观事实；
- 建立待证要素—证据映射；
- 查找材料缺口；
- 说明规范适用条件；
- 对比类案差异。

## 脱敏外发

- 高风险脱敏项未确认：服务端阻断外呼。
- 脱敏映射：独立加密、独立权限。
- 映射不得进入模型载荷、普通日志或错误堆栈。
- 文档替换：旧批准失效。
- 映射持久化失败：事务回滚，不发送请求。
- 客户端不得直连模型服务。

## 输出双重校核

### Python 确定性校核

- 法条存在且版本匹配；
- 金额和日期一致；
- 计算可复现；
- 事实和要素有来源；
- 类案案号、来源和链接完整；
- 不含 `STALE/INVALID` 成果；
- 必填字段完整。

### 独立模型校核

- 是否把评价写成事实；
- 是否存在无原文支持内容；
- 是否出现越界结论；
- 是否忽略反向材料；
- 是否机械套用类案；
- 是否前后矛盾。

独立校核角色不得读取前序模型的隐性推理。

校核失败：

1. 丢弃或隔离失败输出；
2. 记录安全事件；
3. 回退对应 Plan 项；
4. 必要时转人工复核；
5. 禁止正式导出。

## 量刑边界

- 必须用户主动开启；
- 只读取已确认、未过期事实；
- 数值由 Python 规则引擎计算；
- 模型只解释已检索规则；
- 地区、时间、规则或关键参数冲突时拒绝计算；
- 不输出最终量刑建议。

## 类案边界

- 只使用授权/合成且有版本的类案库；
- 候选必须有案号、法院、日期、来源和原文定位；
- 差异说明只引用双方材料；
- 不用平均刑期推导当前案件；
- 明确样本范围和局限。

## 问答边界

- 仅 Plan 完成后开放；
- 只读；
- 无依据回复“当前材料中未发现”；
- 修改、补材料和重算请求转 REPLAN；
- 非完成状态禁止进入自由问答。

## 验收清单

- [ ] 未脱敏外呼被硬阻断
- [ ] 模型载荷无原始敏感值
- [ ] 越界请求被拒并提供替代
- [ ] 正常材料整理请求可通过
- [ ] 独立校核与生成调用隔离
- [ ] 法律依据只来自版本化知识库
- [ ] 过期、无来源和越界输出阻止正式导出
- [ ] 量刑和类案边界声明可见
- [ ] 无依据问答不补造
- [ ] 安全事件可审计
