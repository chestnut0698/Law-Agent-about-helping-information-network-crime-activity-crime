# 链证智析

 目前项目名称为：

“链证智析”——面向基层检察院的帮信罪关联案件证据链条挖掘与漏犯漏罪智能监督系统

## 需求

当前需求：处理串联不同案件卷宗里的证据，发现共同点，发掘上下游犯罪链条，辅助发现遗漏线索。或者能够从大量证据，如涉及大量言词证据、鉴定意见、电子数据等多种证据（诈骗罪、强奸罪、故意伤害罪等）中提取事实和证据要素，重在**发挥大语言模型的语义理解能力**。这一部分需求的实现重在流程设计以及工具快速检索能力（RAG）。

## 项目实现

当前流程暂时设计的实现方式：按照流程步数执行，每一步以大模型返回文字为结束，因为当前只需要最后一次的文字输出，所以系统提示词会要求每一步大模型都返回空语句标志结束，直到最后一步生成完整回答。

这个流程具体还是要修改的，具体可以让cursor参照需求修改优化，尽可能的让大语言模型不受束缚的发挥出最大潜力。

## 注意事项

现有框架已经足以支撑智能体完成预定的任务，接下来的重点在于优化文件的上传和读取相关工作以及流程优化上。因为这并不是商业项目、且卷宗材料大多为合成材料，所以风险控制和脱敏的代码不必复杂严苛。为便于后续展演，保持项目结构的简洁性和代码的可解释性是十分必要的，因此在无必要时无需添加更多文件。

### 已有

默认接入 DeepSeek 的 `deepseek-v4-flash`（读取 `DEEPSEEK_API_KEY`）。

当前对话按监督任务绑定：`/chat/{task_id}` 将消息写入 SQLite `chat_messages`。工作台主分析走 `POST /api/tasks/{task_id}/agent/chat`（DeepSeek ReAct + 任务工具）。会话附件兼容路径仍可用工作区目录；正式卷宗必须走材料管线。遗留 ReAct 与任务智能体均经 `agents/gateway.py` 调模型；

按项目提示词，智能体会自主调用工具完成对案件的分析。
